# VHOX // SYSTEM — visual prototype

This directory is intentionally a **static visual study**. It does not alter the profile README, GitHub Actions, or the current snake animation.

Open `index.html` in a browser to review the complete composition. The visual language is designed to become a set of GitHub-safe SVG panels later:

- near-black `#080d14` foundation;
- hairline electric-blue outlines, softened with opacity;
- low-saturation blue, deep green, and violet ambient light;
- editorial spacing with a large title hierarchy;
- monospaced labels for system metadata;
- one full-width panel per narrative section rather than a dashboard of badges.

The numbers shown in `PROFILE.SIGNAL` were checked against the public GitHub profile on 2026-10-26: 0 stars, 1 public repository, and 8 followers. Contribution count is deliberately shown as `LIVE` in this visual-only phase, because the requested live value requires a later GitHub data workflow.
